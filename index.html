~/dotfiles

A reproducible developer environment built on Zsh, mise, just, and uv that also runs a solo operator's agent fleet: one hub-and-spoke instruction set for five agent CLIs, 141 declared skills, and a complete local-dev stack with datastore and SaaS emulators, OpenTelemetry, and stable https://*.localhost routing. Agents build, gates verify, a human approves.

# runs on macOS, Linux, WSL, and native Windows. MIT. revised 2026-09-07 by hironow
